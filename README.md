### ❄️ The Frost Ecosystem

A cohesive suite of declarative system infrastructure, Wayland desktop tooling, and hermetic utilities built around NixOS.

| Project | Overview |
| :--- | :--- |
| **[Frost](https://github.com/SpanishSyntax/Frost)** | Modular, declarative **NixOS** starter framework & flake distribution with 110+ granular modules across system services, Wayland desktops, and dev environments. |
| **[Borealis](https://github.com/SpanishSyntax/Borealis)** | Telemetry-driven dynamic wallpaper engine for Linux & Wayland that syncs desktop ambiance with celestial mechanics, real-time weather, and geomagnetic solar storms. |
| **[Flaker](https://github.com/SpanishSyntax/Flaker)** | Fast CLI for scaffolding modular `flake.nix` dev environments, `direnv` hooks, and starter templates across 20+ language ecosystems. |
| **[Folio](https://github.com/SpanishSyntax/Folio)** | Zero-dependency, hermetic **Markdown + LaTeX → Typst PDF** compiler for publication-grade documents. |
| **[Firn](https://github.com/SpanishSyntax/Firn)** | Instant, zero-clutter native desktop viewer for GitHub-Flavored Markdown. |
| **[Glaze](https://github.com/SpanishSyntax/Glaze)** | Ultra-fast filename sanitizer, case transformer, and batch rename engine. |
| **[Airlock](https://github.com/SpanishSyntax/Airlock)** | Fluid Material 3 Expressive `greetd` display manager frontend crafted with Quickshell and Qt6. |

### 🛠️ Selected Hardware & Software

- **[PiTTY](https://github.com/SpanishSyntax/PiTTY)**: A 33-key QAZ portable cyberdeck & terminal built on a Raspberry Pi CM4, inspired by the classic TRS-80 Model 100.
- **[Tablemind](https://github.com/SpanishSyntax/Tablemind)**: AI-powered spreadsheet assistant that operates row-by-row to automate messy tabular workflows.
- **[Dao](https://github.com/SpanishSyntax/Dao)**: Mandarin learning app featuring spaced repetition, gamified tracking, and speech feedback.
- **[IIP Visualizer](https://github.com/LABCapital-VD/Visualizador-IIP)**: Interactive Svelte application for exploring Bogotá's Public Innovation Index.
- **[Archer](https://github.com/SpanishSyntax/Archer)**: Automated Arch Linux setup with Btrfs, full-disk encryption (including `/boot`), and out-of-the-box Snapper rollback.
